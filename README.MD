# AI Voice Assistant

An AI-powered virtual voice assistant built using Python.

## Features
- Speech Recognition
- Female Voice Response
- Open Applications
- Open Websites
- Search Google
- Wikipedia Search
- Time Announcement

## Technologies Used
- Python
- SpeechRecognition
- pyttsx3
- PyAudio
- Wikipedia API

## Commands
- Open Google
- Open YouTube
- Open WhatsApp
- Open VS Code
- Search Python
- Tell me the time
